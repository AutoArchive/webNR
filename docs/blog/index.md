# WebNR Blog

这里不是运营日志，也不是书源审计流水账。Blog 只保留对读者有用的三类内容：**怎么读、去哪找、怎么判断是否适合自己**。如果你第一次来，按下面的路线读，不需要从时间线第一页开始翻。

## 阅读说明

文章分两种。**实用指南**会把可执行结论放在最前面；**研究 / 生态文章**会保留方法和来源，但这些材料不会再挤占 Blog 首页。来源接入的逐日候选、CI、部署 commit、审计流水和内部运营决定属于仓库运营记录，不应该伪装成读者正文。
